# Pro Récup

Pro Récup est une plateforme de gestion environnementale permettant de suivre l’ensemble du cycle de récupération des déchets recyclables.

La plateforme centralise la gestion des clients, des sites de collecte, des collectes, des lots, des stocks, des ventes et de l’impact carbone.

---

## Objectif du projet

L’objectif de Pro Récup est de fournir une solution simple et sécurisée pour gérer les opérations suivantes :

```text
Client
→ Site de collecte
→ Collecte
→ Validation
→ Création d’un lot
→ Mise à jour du stock
→ Vente
→ Calcul de l’impact carbone
