# Pro Récup

Auteur : Chris

## Vision

Pro Récup est une plateforme SaaS permettant de gérer les activités de collecte, de transformation et de valorisation des déchets.

## Objectif du MVP

Construire une première version fonctionnelle permettant :

- gérer les organisations
- gérer les utilisateurs
- gérer les clients
- gérer les collectes
- gérer les stocks
- gérer les ventes
- produire des rapports
