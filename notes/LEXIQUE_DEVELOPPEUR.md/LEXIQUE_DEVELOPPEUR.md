# Lexique du développeur

## API
Programme qui permet à deux logiciels de communiquer.

## Backend
Partie du logiciel qui traite les données.

## Frontend
Partie visible par l'utilisateur.

## Base de données
Endroit où sont stockées les informations.

## SQL
Langage utilisé pour créer et manipuler une base de données.

## Git
Outil qui permet de suivre l'historique du code.

## UUID
Identifiant unique universel.
